# Security

## Reporting a vulnerability

Please report security problems privately, not in a public issue.

1. On the repository concerned, open the **Security** tab and choose **Report a vulnerability**. This sends a private report to the maintainers.
2. If that option is not available, use the contact form at [aryabhattalabs.com](https://aryabhattalabs.com/#contact) and say it is a security report. Give no details in the form; we will reply with a private channel.

A good report includes the affected version, the steps to reproduce, and what an attacker could do.

## What to expect

- We will confirm that we received the report.
- We will tell you whether we can reproduce it, and what we plan to do.
- We will credit you in the release notes when the fix ships, unless you prefer not to be named.

Please give us a reasonable time to fix the problem before you publish details.

## Scope

This policy covers the tools published under [github.com/AryabhattaLabs](https://github.com/AryabhattaLabs). For the products (JoeHukum, NibbleIQ, RoleGPS, Favseen), use the contact form above.
